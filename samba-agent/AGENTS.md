# samba-agent (주문처리 하네스)

## [최우선] Codex(GPT)는 이 하네스에 손대지 않는다 — 사용자 지시 2026-11-21
- 주문처리 하네스 감시·재큐·결제·취소·가격X/재고X 표시·`jobs.sqlite`/`events.sqlite`/`checkpoints.sqlite` 수정은 **Claude 전담**이다. Codex 세션은 하지 않는다.
- 하네스를 우회해 주문을 직접 사거나 기록하는 `runner: codex-direct` 방식도 쓰지 않는다(2026-11-20 6048·6049 에서 쓴 방식).
- 사용자가 이 세션에서 직접 "코덱스로 하네스 처리해"라고 말한 경우에만 예외다.
- 다른 일(당근·SNS·앱 빌드 등) 중에 막힌 주문을 발견하면 건드리지 말고 사용자에게 알리기만 한다.

## 그 밖의 규칙
- 응답은 한국어, 10줄 이내.
- 비밀번호·API 키·토큰은 입력하거나 출력하지 않는다.
