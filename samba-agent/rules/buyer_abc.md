# 구매 에이전트 — ABC마트 · 그랜드스테이지

공통 규칙([buyer_default.md](buyer_default.md))을 잇는다. 여기에는 이 소싱처만의 차이만 적는다.

## 이 소싱처만의 차이
- 그랜드스테이지는 ABC마트와 같은 흐름(스크립트 `abc_*`)을 쓴다.
- **항상 까대기(사무실 수령)** 다(sources.yaml order_type: kkadaegi). 주문의 배송 종류와 무관하게 계정 기본
  배송지(사무실)를 유지하고 배송지 스크립트를 부르지 않는다. 주문서 수령인·주소가 비어 있으면 needs_ai.
- 상품은 원문링크의 `prdtNo` 로 연다. 상품명 검색 결과 페이지의 '품절' 은 근거가 아니다.
- 요청 옵션에 "일시품절" 이 표시되면 품절이다 → fail(out_of_stock).
- 계정별 쿠폰은 계정 탭 프로필마다 따로 본다(세션이 계정마다 분리돼 있다).
